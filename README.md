## `> whoami`

I build practical tools for everyday IT operations — from Telegram bots and database integrations to infrastructure workflows and network labs.

Создаю практичные инструменты для внутренних IT-процессов: автоматизирую рутину, связываю сервисы и превращаю сложные операции в понятные рабочие сценарии.

- ⚡ Automating task, asset and inventory workflows
- 🤖 Building Telegram interfaces for internal services
- 🗄️ Connecting applications to Microsoft SQL Server
- 🌐 Growing in networking, infrastructure and systems engineering
- 🛠️ Shipping useful solutions first, then making them cleaner and stronger
